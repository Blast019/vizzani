# Vizzani Estética — App

App web (PWA) da Vizzani Estética Automotiva, Uberlândia/MG: agendamento, acompanhamento do carro,
histórico, fidelidade, Clube de assinatura e painel da loja.

- Front-end: HTML, CSS e JavaScript puro (`index.html`, `style.css`, `script.js`, `config.js`).
- Backend: Supabase (Postgres com RLS, Auth, Storage e Edge Functions).
- `config.js` tem só a URL do projeto e a chave pública (publishable). As regras de segurança ficam no servidor.
